# default-outsourcing-project 安全规则

适用于传统软件外包项目资产包 MVP。

## 默认排除

不得读取、复制或输出以下内容：

- 生产数据库备份
- 客户真实业务数据
- 账号、密码、Token、密钥、证书
- 数据库生产连接串
- 合同金额、报价和客户商业策略
- 未经授权的第三方资料
- 客户明确限制外传的文档

## 默认脱敏

如需描述，只能写类型和用途，不得写原值：

- 客户名称
- 个人姓名、手机号、邮箱、身份证号
- 服务器地址和内网地址
- 数据库连接串
- 第三方系统账号
- 业务单据编号
- 真实交易流水

## 输出分级

每个资产或结论可以标注：

- 可内部公开
- 仅项目组可见
- 仅管理层可见
- 不可输出

## 处理原则

- 发现敏感信息时，只记录“发现疑似敏感信息类型”和所在文件类别。
- 不在输出中粘贴敏感原文。
- 对不确定是否敏感的内容，按敏感内容处理。
- 可复用资产候选必须经过人工确认后，才能进入公司级资产库。
