# 客户沟通摘要

## 背景

客户是一家小型设备服务公司，目前主要通过 Excel 和微信群跟踪设备巡检、维修派单和客户反馈。

随着客户数量增加，现有方式已经出现信息分散、派单不透明、维修记录难追溯的问题。

## 初步目标

- 建立一个轻量级工单管理系统。
- 支持客户报修、内部派单、维修记录、工单状态跟踪。
- 支持管理人员查看工单进度和基础统计。

## 已知约束

- 第一阶段优先解决工单流转，不做复杂 BI。
- 客户希望能在普通浏览器中使用。
- 暂未确认是否需要移动端小程序。
- 暂未确认是否需要对接现有客户系统。

## 待确认问题

- 是否需要客户账号体系。
- 是否需要短信或微信通知。
- 是否需要导入历史 Excel 数据。
- 工单状态和维修类型是否已有固定规范。
