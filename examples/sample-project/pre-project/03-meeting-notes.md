# 立项前会议纪要

会议日期：示例日期

## 参会视角

- 客户负责人
- 业务使用代表
- 外包团队项目负责人
- 外包团队技术负责人

## 会议结论

- 客户当前最关心的是工单过程可追踪。
- 第一阶段可以接受功能简单，但流程必须清楚。
- 客户倾向先使用 Web 系统。
- 测试环境由外包团队先提供，正式环境后续再确认。

## 需要客户补充

- 当前工单 Excel 样例。
- 维修类型和状态定义。
- 用户角色和权限边界。
- 是否存在必须保留的历史编号规则。

## 外包团队建议

- 先做一版最小可用流程。
- 第一阶段不要引入复杂统计和外部集成。
- 启动阶段先确认工单状态、角色权限和验收流程。
