# 投标范围草案

## 本期计划交付

1. 工单登记。
2. 工单列表和状态筛选。
3. 派单和处理记录。
4. 基础用户角色：管理员、调度员、维修人员。
5. 简单统计：待处理、处理中、已完成工单数量。
6. 部署说明和基础操作说明。

## 本期暂不交付

1. 复杂数据看板。
2. 客户自助门户。
3. 移动端小程序。
4. 第三方系统集成。
5. 历史数据清洗和批量迁移。

## 验收初稿

- 能完成从工单登记到完工归档的基本流程。
- 不同角色只能看到对应范围内的功能。
- 管理员能查看基础工单统计。
- 系统能在客户指定测试环境运行。

## 风险提示

- 客户是否有明确工单流程仍待确认。
- 维修人员是否需要移动端使用仍待确认。
- 历史 Excel 是否要导入会影响第一阶段范围。
