# 生成面向人类的问题清单

用于在信息对齐、全周期规划、阶段计划或阶段执行中发现缺口后，生成面向人类的问题清单。

## 输入

1. `docs/agent-workflows/workbench-overview.md`
2. 项目配置和安全规则
3. 当前工作台输出和人工确认记录
4. 当前阶段计划或阶段报告，如果存在

## 输出

写入：

```text
outputs/generated/workbench/human-questions.md
```

## 规则

1. 问题必须按责任视角归类。
2. 每个问题说明为什么需要确认。
3. 每个问题标注会影响的阶段或交付物。
4. 不问已经能从资料中确认的问题。
5. 涉及敏感内容时只描述类型，不要求用户粘贴原值到输出文件。
